# StoryEnquete

Story de interação para enquetes, perguntas e caixinhas.

- Fundo `grafite`, logotipo no topo, rótulo em `etiqueta`.
- Pergunta em Sora 800, no máximo 10 palavras.
- Opções em cartões `ardosia`; a primeira em `ultramar` com texto `branco`.
- Use para validar temas de minicurso antes de produzir.
