# Botao

Botão de chamada para ação, com texto curto que diz exatamente o que acontece.

- **Principal**: fundo `acao`, texto `sobre-acao`, Sora 700. Um por tela ou peça.
- **Secundário**: fundo transparente, borda `borda`, texto `texto`.
- Cantos `raio-sm`, padding de 12 × 20px, foco com contorno em `destaque`.
- Textos: "Quero o guia grátis", "Comente GUIA", "Ver curso". Nunca "Clique aqui".
