# CaixaPrompt

A caixa de prompt mostra qualquer comando de IA para o público copiar; é a marca registrada do perfil.

- Fundo `ardosia`, borda `linha`, cantos `raio-md`, padding `espaco-3`, nos dois temas.
- Etiqueta em `etiqueta` na cor `ultramar-luz`: "Copie este comando".
- Texto em `prompt` (JetBrains Mono 14px) na cor `papel`.
- Partes que a pessoa deve trocar ficam entre colchetes: [cole aqui].
