# Destaques

Capas dos destaques do Instagram.

- Círculo `grafite` com ícone de linha em `papel`, traço de 1,8px e pontas arredondadas.
- Só "Guia grátis" usa fundo `ultramar`, porque é o destaque mais importante.
- Ordem: Guia grátis, Comece, Ferramentas, Automação, Bastidores.
- Exporte em 1080 × 1920 px com o ícone centralizado em 400px.
